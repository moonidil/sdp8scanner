- input handling
- preprocessing

- cyclomatic complexity integration
- security red-flag detection
- vulnerability density calculation
- TDI calculation
- risk classification
- CLI output
- raw JSON output
- Streamlit dashboard output
- dashboard file upload scanning
- dashboard visualisations
- export support
- Refactoring Impact Simulator
- basic pytest coverage for metric calculations

The previous placeholder fields for redFlags and tdi have now been replaced with working values.

Setup Before Running

1. Check Python is installed:

python3 --version

If this does not work, install Python 3 from the official Python website or use Homebrew on Mac:

brew install python

2. Upgrade pip:

python3 -m pip install --upgrade pip

3. Install dependencies:

python3 -m pip install -r requirements.txt

4. Check Streamlit is installed:

streamlit --version

If the streamlit command does not work, run the dashboard using:

python3 -m streamlit run src/app.py

How to Run the CLI Version

From the project root, run the default snippet demo:

python3 src/main.py

Run a low-risk file scan:

python3 src/main.py samples/test.py

Run the main high-risk demo scan:

python3 src/main.py samples/full_demo_risk.py

The CLI prints a readable summary and raw JSON output.

How to Demo the Dashboard

From the project root, run:

streamlit run src/app.py

Alternative if the streamlit command is not recognised:

python3 -m streamlit run src/app.py

Then open the local URL shown in the terminal, usually:

http://localhost:8501

Known Limitations

- The prototype currently supports Python only
- The scanner processes one file or pasted snippet at a time
- Repository-level scanning is not implemented and remains future work.
- Security detection is pattern-based and explainable, not a full static analysis engine
- Pattern-based rules may produce false positives or miss issues requiring deeper program analysis
- Vulnerability density can appear high on small files because it is calculated per 1,000 lines of code
- The high-risk alert follows the project threshold of TDI >= 50
- The Refactoring Impact Simulator provides projected impact only. It does not automatically rewrite or rescan refactored code 
- Complexity calculation depends on the agreed decision-point approach and is documented by Abdul
